# Assets - Music Folder
Letakkan file lagu/instrumen musik pernikahan (background music) di folder ini.
Format file audio yang didukung secara optimal di seluruh browser: .mp3.

Ganti nama file musik Anda menjadi "background-music.mp3" untuk memudahkan integrasi, atau sesuaikan nama file di bagian tag <audio> pada index.html.
